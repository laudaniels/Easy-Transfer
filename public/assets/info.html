How to use PsiTransfer?

  • Drag-and-drop multiple files or one or more folders (including subfolders) onto the drop-off page — the folder structure is preserved.
  • Click on the “+ Drop your files here” to select individual files, or use the folder icon to select a whole folder at once.
  • Uploaded folders show up as a clickable folder tree — select a folder to see just its contents, both when uploading and when downloading.
  • If needed change the retention time and fill in a password
  • Click the upload button
  • Share the download link… that's it.

Get notified when your file is downloaded

  • Tick “Notify me by email when this is downloaded” on the upload page and enter your email address.
  • You'll receive one email the first time any file in that share is downloaded — further downloads of the same share won't send additional emails, so your mailbox doesn't fill up if many people download the same files.
  • The notification email is just an alert — it does not contain a download link or the file itself.

How secure is PsiTransfer?

  • All files are transferred across the internet securely encrypted with https.
  • Uploaded data is only held for a maximum of the retention time set during upload, after which time it is automatically deleted. There is no "undelete" facility available at all.
  • Your files are only accessible with the link provided after the upload. Without that link there's no access to your files.
  • If an uploaded file has been deleted, there is no way of recovering the file.

Personal or confidential data?

  • If you want to sent personal or confidential data, use the password option.
  • The same password must be used when downloading the content.
  • The passphrase is stored encrypted and cannot be recovered if lost.
  • No one can access the files without your password.
Tips:
  • Keep the retention time, which can be set on the upload page, to 1 hour.
  • Email the link to the recipient, call the recipient and inform about the link and exchange the password. do not mail the password!
